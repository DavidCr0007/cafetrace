# Aplicación móvil offline-first — etapa 3

Se deja definido el contrato de implementación: SQLite local, cola de comandos idempotentes, sincronización por cursor y resolución de conflictos por `external_id`/timestamp. La implementación nativa requiere decidir React Native/Expo o Flutter y disponer de pruebas en dispositivos; no se presenta este documento como una app móvil terminada.
